# Security policy

## Reporting a vulnerability

Please do not open a public issue for an unpatched vulnerability. Use GitHub's private vulnerability reporting feature for the repository and include affected versions, reproduction steps, impact and any suggested mitigation.

Maintainers should acknowledge a complete report within seven days. Disclosure is coordinated after a fix or mitigation is available. No bounty is currently promised.

## Supported versions

Until the first stable release, only the newest tagged release receives security fixes. Self-hosters should keep an encrypted backup before every update and subscribe to repository security advisories.

## Scope boundaries

Scope stores local account data, project content, private attachments and encrypted AI provider secrets. Operators are responsible for TLS termination, host patching, database and backup security, SMTP credentials and access to optional model services.
